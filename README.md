# minical — A Modern C++ Calendar CLI

`cal` 命令的面向对象 C++23 实现，支持单月、多月和全年日历显示。

## 功能

- 显示指定年月的文本月历（含英文标题、星期表头、日期网格）
- 支持多个月份横向拼接，每排数量可调
- 自动处理跨年月份范围
- 基于 GoogleTest 的完整测试覆盖

## 构建与运行

```bash
# 构建
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build

# 运行测试
./build/cal_test
# 或
ctest --test-dir build
```

## 使用示例

```bash
./build/minical 2025           # 显示 2025 全年，每排 3 个月
./build/minical -m 5           # 显示今年 5 月
./build/minical -A 2           # 显示当月及之后 2 个月
./build/minical -B 2           # 显示当月及之前 2 个月
./build/minical -r 4 2025      # 显示 2025 全年，每排 4 个月
./build/minical -d 2025-12     # 显示 2025 年 12 月
./build/minical -A 3 -B 1      # 显示前 1 个月 + 当前 + 后 3 个月
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-A N` | 之后 N 个月（不含当前月），N ≥ 0 | 0 |
| `-B N` | 之前 N 个月（不含当前月），N ≥ 0 | 0 |
| `-d yyyy-mm` | 指定日期，如 `2025-06` | 当天 |
| `-r N` | 每排显示月数，N ≥ 0 | 3 |
| `-m N` | 指定月份，1–12 | 当月 |
| `yyyy` | 位置参数，指定年份，1–9999 | 当年 |

## 已知不足

| 问题 | 说明 |
|------|------|
| `-m` 与 `-d` 优先级 | 当同时指定 `-m` 和 `-d` 时，`-m` 的值覆盖 `-d` 中的月份。直觉上更具体的 `-d` 应该胜出，更合理的做法是"后出现的覆盖先出现的" |
| 仅支持公历 | 闰年规则和月份天数硬编码（Gregorian），无法显示农历日期 |
| 仅英文输出 | 月份名和星期表头固定为英文，不支持本地化 |
| 周日为首 | 每周固定从周日开始，不支持 `-s` 类标志切换周一为首 |
| 无帮助信息 | 不支持 `-h` / `--help`，非法参数错误信息较简略 |

## 未来规划

- [ ] **农历支持**：抽象日期计算接口，增加中国农历（阴阳历）显示
- [ ] **本地化**：支持 `LANG` 环境变量，根据 locale 输出不同语言的月份名和星期
- [ ] **`-s` 标志**：允许以周一为每周第一天
- [ ] **`-3` 标志**：快捷显示上个月 + 当前 + 下个月
- [ ] **`-h` / `--help`**：生成帮助信息，列出所有可用参数
- [ ] **彩色输出**：用 ANSI 颜色高亮当天日期
- [ ] **性能基准**：基于 Google Benchmark 建立性能回归测试
