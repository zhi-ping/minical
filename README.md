# minical — 基于 C++23 的命令行日历查看工具

`minical` 命令的面向对象 C++23 实现，支持单月、多月和全年日历显示。

## 功能

- 显示指定年月的文本月历，含英文标题、星期表头和日期网格
- 多个月份横向拼接，每排月数可调
- 自动处理跨年月份范围
- 基于 GoogleTest 的完整测试覆盖

## 依赖

- **编译器**：GCC ≥13 或 Clang ≥18（需支持 C++23）
- **构建工具**：CMake ≥3.16
- **第三方库**：GoogleTest、Google Benchmark（通过 `FetchContent` 离线拉取，无需网络）

## 安装

```bash
git clone git@github.com:zhi-ping/minical.git
cd minical
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

安装到系统路径（可选）：

```bash
cmake --install build --prefix /usr/local
```

## 快速开始

```bash
# 查看帮助（命令行参数一览）
# TODO: 参见 #路线图

# 显示当月日历
./build/minical

# 显示指定月份
./build/minical -m 12

# 显示指定年份全年
./build/minical 2025

# 显示前后各 2 个月
./build/minical -A 2 -B 2

# 显示 2025 年全年，每排 4 个月
./build/minical -r 4 2025

# 运行测试
./build/cal_test
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-A N` | 之后 N 个月（不含当前月），N ≥ 0 | `0` |
| `-B N` | 之前 N 个月（不含当前月），N ≥ 0 | `0` |
| `-d yyyy-mm` | 指定日期，如 `2025-06` | 当天 |
| `-r N` | 每排显示月数，N ≥ 0 | `3` |
| `-m N` | 指定月份，1–12 | 当月 |
| `yyyy` | 位置参数，指定年份，1–9999 | 当年 |

## 已知问题

- **`-m` 与 `-d` 优先级**：同时指定时 `-m` 覆盖 `-d` 中的月份，与直觉不符。计划改为"后出现的覆盖先出现的"
- **仅公历**：闰年规则和月份天数硬编码，无法显示农历日期
- **仅英文输出**：月份名和星期表头固定英文，未对接 locale
- **首周日**：每周固定周日开始，无 `-s` 选项切换为周一
- **无 `--help`**：不支持 `-h` / `--help`，错误信息简略
